The 3.2 release of Agroal is a maintenance release to address some issues identified after 3.1. It includes a new feature to help integration on Spring Boot environments.

Also, there were 3.0.2, 2.8.2 and 2.7.3 releases that backport the fix for AG-304 (Fix interleaving issue with the Narayana reaper thread) to those streams.

## Feature Request

* [AG-312](https://redhat.atlassian.net/browse/AG-312) Allow Spring Boot applications to configure custom `AgroalDataSourceListener` beans on the Agroal DataSource

## Bug

* [AG-308](https://redhat.atlassian.net/browse/AG-308) `setTransactionIsolation` only applied to the first connection created by the pool
* [AG-309](https://redhat.atlassian.net/browse/AG-309) Clear held-over-commit state on flush to prevent connection leak after XA commit failure
* [AG-310](https://redhat.atlassian.net/browse/AG-310) Logical error in `ConnectionWrapper.hasTrackedStatements\()`
* [AG-311](https://redhat.atlassian.net/browse/AG-311) Connection leaks when multiple wrappers exist in enlistedOpenWrappers list

## Task

* [AG-313](https://redhat.atlassian.net/browse/AG-313) Skip deployment of integration tests module
